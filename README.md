# CatCafeSim Lite

Unity 2021.3.45f2 でこのフォルダを開き、`Assets/Scenes/CatCafeTitle.unity` を再生します。自由営業・人気目標・好感度目標から開始できます。初期猫はミケ・タマ・ソラで、3匹の個別イベントは各5件です。

軽量版の保存と設定には `CatCafeSimLite` のプロファイルを使います。新しいゲームから始めてください。

元の Unity プロジェクトのコミット `a6fa998019a712cf03ca3c8d26385f23edc88448` を基準にした開発用プロジェクトです。M PLUS フォントの権利表示は `Assets/CatCafePreview/Fonts/OFL.txt` を参照してください。
